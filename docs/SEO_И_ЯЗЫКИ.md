# SEO, английская версия и статьи

Обновлено: 2026-11-05.

## Что есть на сайте

| Что | Адреса | Где править |
|---|---|---|
| Русская версия | `/`, `/nomera`, `/booking`, … | страницы в `frontend/app/(site)` |
| Английская версия | `/en`, `/en/rooms`, `/en/booking`, `/en/contacts`, `/en/payment` | страницы в `frontend/app/en`, тексты в `frontend/lib/en.ts` |
| Посадочные страницы (одна страница — один поисковый запрос) | RU: `/gostinica-v-centre-almaty`, `/otel-dlya-komandirovki`, `/gostinica-ryadom-s-centralnym-stadionom`, `/gostinica-s-zavtrakom`, `/gostinica-posutochno`. EN: `/en/almaty-city-centre-hotel`, `/en/business-hotel-almaty`, `/en/hotel-near-central-stadium-almaty` | `frontend/lib/articles.ts` |
| Путеводитель по Алматы | `/almaty`, `/en/almaty` и 4 статьи на каждом языке | `frontend/lib/articles.ts` |
| Справка для ИИ-поисковиков | `/llms.txt` | `frontend/app/llms.txt/route.ts` |

Казахский язык по-прежнему делает Google Translate поверх русских страниц.

## Как работают языки

- Пары «русская страница ↔ английская» перечислены в `frontend/lib/routes.ts` (`PAGE_PAIRS`). Пары номеров считаются сами: `/nomera/x` ↔ `/en/rooms/x`.
- По этим парам строятся ссылки hreflang для Google, карта сайта и переключатель RU/KZ/EN.
- Ссылки вида `?lang=en` (бот в WhatsApp, старая реклама) прокси перенаправляет на английскую пару. Метки `utm_*`, `gclid` и параметры брони сохраняются. Код — `frontend/proxy.ts`.
- Если гость выбрал EN, выбор запоминается. Русская страница, у которой есть пара, сама уводит на английскую. Страница без пары (оферта, политика) переводится переводчиком.
- Форма Exely на `/en/...` всегда открывается по-английски.

## Как добавить статью

1. Добавить адрес в `PAGE_PAIRS` в `frontend/lib/routes.ts`. Если у статьи нет пары на другом языке — `null` на месте пары.
2. Добавить статью в `frontend/lib/articles.ts`: заголовок, описание, текст блоками.
   - Внутри текста работают `**жирный**`, `[ссылка](/путь)` и `{priceFrom}`.
   - Готовые блоки: `rooms` (номера с ценами), `airport` (маршруты из аэропорта), `events`, `nearby`, `cta`.
3. Запустить `npm run build`. Если адрес забыли внести в `PAGE_PAIRS`, сборка упадёт с понятной ошибкой.

Правило для текстов: только факты из `frontend/lib/site.ts` и общеизвестное о городе. Где точной цифры нет (номер автобуса, часы работы), статья отправляет в 2ГИС, а не называет число наугад.

## Если поменялся факт

Русские данные живут в `frontend/lib/site.ts`: их же читает консьерж. Английские повторы — в `frontend/lib/en.ts`. Поменяли время завтрака, цену раннего заезда, расстояние или маршрут — исправьте в обоих файлах. Цены номеров меняются в админке и доходят до обоих языков сами.

## Что сделать вне кода

- Google Ads, кампания `Europe_Search_EN`: в поле «Конечный URL» поставить `https://airisresidence.kz/en`. Старый адрес `/?lang=en` тоже работает, но через перенаправление.
- Search Console: отправить карту сайта заново, чтобы новые страницы нашлись быстрее.
- Яндекс Вебмастер и Bing Webmaster Tools: добавить сайт и карту сайта `https://airisresidence.kz/sitemap.xml`.
