## Для почты

**Тема:** Airis Residence — сайт готов к подключению бронирования

Здравствуйте!

Сайт отеля Airis Residence запущен и работает: https://airisresidence.kz

С нашей стороны всё готово к подключению вашей системы. Менять код не
потребуется — интеграция включается переменными окружения, поэтому
подключение занимает не больше часа и не требует пересборки сайта.

**Что нужно от вас — что-то одно из трёх:**

1. **Ссылка на страницу бронирования.** Мы подставим её во все кнопки
   «Забронировать» и будем передавать даты, число гостей и тип номера
   прямо в адрес.

2. **Код виджета** (`<script>` + контейнер). Разместим на странице
   https://airisresidence.kz/bronirovanie — блок под него уже готов.

3. **Доступы к эквайрингу**, если платёж проводит наш сервер:
   `client_id`, `client_secret`, `terminal_id`, адрес API, секрет
   подписи. Каркас интеграции написан под протокол Halyk ePay 2.0.

**Коды типов номеров.** Сайт передаёт: `standart-single`, `standart`,
`standart-twin`, `comfort`, `comfort-plus`. Актуальные названия,
площади и цены отдаёт открытый эндпоинт, авторизация не нужна:

```
https://airisresidence.kz/api/backend/api/rooms
```

Обратите внимание: `comfort` и `comfort-plus` — разные категории
с разной ценой.

**Адрес для колбэка об оплате.** Пропишите в личном кабинете:

```
https://airisresidence.kz/api/backend/api/payments/callback
```

**Как проверить подключение:**

```
curl https://airisresidence.kz/api/backend/health
```

Поле `payments_configured` должно стать `true`. Пока оно `false`,
эндпоинты оплаты отвечают `501` — это штатное поведение, сайт
продолжает принимать заявки через форму.

Во вложении — подробная инструкция со всеми переменными, примерами
запросов и разбором каждого варианта.

Секреты, пожалуйста, передавайте не письмом, а защищённым каналом.
